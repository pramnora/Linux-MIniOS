MINI-OS INFO.

Apparently, MiniOS comes in 3 different versions...  

- MiniOS Standard  
- MiniOS Toolbox  
- MinoOS Ultra  

...I'm running the standard version.  

**NOTE**: MiniOS can be run from a live external USB disk.  

HOW TO UPDATE AND UPGRADE 'ALL' SYSTEM PACKAGES

The command to update and upgrade all system packages is...

sudo apt update
sudo apt upgrade -y
